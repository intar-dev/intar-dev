# intar-dev

Monorepo for the intar platform:

- `crates/` contains the Rust workspace for the agent, kino, stargate, and shared contracts.
- `apps/web/` contains the Cloudflare-hosted web and control plane.
- `content/` contains authored Course and Scenario source locks.

Tasks are defined in `env.cue` and run with [cuenv](https://github.com/cuenv/cuenv)
0.56.7. `cuenv task` lists them. Common commands:

```sh
cuenv task install-js
cuenv task check
cuenv task test
cuenv task build
cuenv task check-generated
```

`cuenv task clean-generated` removes only allowlisted repository output. It preserves
the root `node_modules/`, Bun cache, Cargo cache, and root `target/`.

The website database is schema-first. Files under `apps/web/src/db/schema/`
are the only source of truth, and every file under `apps/web/migrations/` must
be generated by Drizzle Kit and committed with its generated `meta/` files.
Never hand-edit migration SQL or metadata, create custom migrations, or add SQL
triggers. Run `bun run --cwd apps/web db:generate` after a typed schema change
and `bun run check:database-migrations` before committing it.

`content/courses/` contains Markdown-first Course source. Each Course contains
`course.md` and ordered Lecture directories. Each Lecture contains `lecture.md`
and can contain a technical `scenario.hcl`. The base image catalog remains at
`content/scenarios/base-images.hcl`.
